
# Веб-ресурсы по Linux-справке

Подборка сайтов, которые удобно использовать для чтения Linux-справки в браузере и перевода через Chrome.

---

## 1. manpages.debian.org
**Ссылка:** [manpages.debian.org](https://manpages.debian.org/)

**Для чего подходит:**
- поиск полных `man`-страниц для Debian
- просмотр справки по пакетам и версиям Debian
- чтение документации в браузере с автопереводом
- удобен, когда нужна именно справка, близкая к Debian-системам

**Когда использовать:**
- если сервер или окружение основаны на Debian
- если нужна точная страница из конкретного пакета

---

## 2. manpages.ubuntu.com
**Ссылка:** [manpages.ubuntu.com](https://manpages.ubuntu.com/)

**Для чего подходит:**
- поиск полных `man`-страниц для Ubuntu
- просмотр справки с привязкой к версиям Ubuntu
- чтение документации в браузере с переводом
- полезен, когда поведение пакета в Ubuntu отличается от других дистрибутивов

**Когда использовать:**
- если вы работаете именно с Ubuntu
- если нужна документация, максимально близкая к установленным пакетам Ubuntu

---

## 3. tldr.inbrowser.app
**Ссылка:** [tldr.inbrowser.app](https://tldr.inbrowser.app/)

**Для чего подходит:**
- быстрый просмотр краткой справки по командам
- изучение типовых примеров использования
- понимание команды без чтения длинной `man`-страницы
- быстрый перевод коротких и простых описаний

**Когда использовать:**
- если нужно быстро понять, как пользоваться командой
- если нужна не полная документация, а практические примеры

**Не лучший выбор для:**
- редких флагов и тонких деталей
- глубокого изучения поведения команды

---

## 4. explainshell.com
**Ссылка:** [explainshell.com](https://explainshell.com/)

**Для чего подходит:**
- разбор готовой shell-команды по частям
- объяснение, что означает каждый флаг и аргумент
- обучение синтаксису командной строки
- анализ чужих команд из документации, форумов и GitHub

**Когда использовать:**
- если у вас уже есть готовая команда и нужно понять, что она делает

**Пример сценария:**
```bash
rsync -avz --delete /src/ user@host:/backup/
````

---

## 5. mankier.com

**Ссылка:** [www.mankier.com](https://www.mankier.com/)

**Для чего подходит:**

* универсальный поиск по `man`-страницам Linux
* удобный просмотр системной справки в браузере
* хороший вариант для RHEL, Rocky Linux, AlmaLinux, CentOS
* быстрый переход между разделами `1`, `5`, `8` и другими

**Когда использовать:**

* если нужен универсальный веб-справочник по Linux
* если вы работаете не только с Debian/Ubuntu
* если нужен удобный аналог веб-справки для RHEL-совместимых систем

---

## 6. man.cx

**Ссылка:** [man.cx](https://man.cx/)

**Для чего подходит:**

* быстрый поиск `man`-страниц по имени
* дополнительный источник, если нужную страницу неудобно искать где-то ещё
* быстрый доступ к справке в виде веб-страниц

**Когда использовать:**

* если нужен запасной или альтернативный индекс `man`-страниц
* если хочется быстро открыть страницу по названию команды

---

# Какой ресурс выбирать по ситуации

## Если нужна полная справка в браузере

* **Debian:** `manpages.debian.org`
* **Ubuntu:** `manpages.ubuntu.com`
* **RHEL / Rocky / Alma / CentOS:** `mankier.com`

## Если нужны короткие практические примеры

* `tldr.inbrowser.app`

## Если нужно разобрать длинную готовую команду

* `explainshell.com`

## Если нужен дополнительный общий индекс

* `man.cx`

---

# Практический набор для работы


* **Debian / Ubuntu:** `manpages.debian.org`, `manpages.ubuntu.com`
* **RHEL / Rocky / Alma / CentOS:** `mankier.com`
* **быстрые примеры:** `tldr.inbrowser.app`
* **разбор сложных команд:** `explainshell.com`
* **резервный поиск:** `man.cx`

---

# Короткий вывод

Если нужна **полная системная справка**, лучше использовать `manpages.debian.org`, `manpages.ubuntu.com` и `mankier.com`.

Если нужно **быстро понять команду**, лучше использовать `tldr.inbrowser.app`.

Если нужно **разобрать конкретную длинную команду по частям**, лучший выбор — `explainshell.com`.
